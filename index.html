Multidisciplinary Communication Designer based in Milan. Currently pursuing a Master’s degree in Digital and Interaction Design at Politecnico di Milano. Passionate about design as an inquiry, provoking reflection and merging visual aesthetics with meaningful narratives. Mastering the rules to break them.

Project 01

Soema

2026

Speculative Design

Interaction Design

Academic Project

Soema is a speculative design project exploring infrastructural conflict. An interactive sample collection allows users to physically touch macabre future building materials, created by recycling bodies of human victims for an exclusive showroom in 2052.

2026

ALab

Exhibition Design

Side Project

"Undeclared" showcases Politecnico di Milano Communication Design projects using speculative design to expose hidden conflicts. Through destabilizing near-future scenarios, the exhibition questions societal structures we take for granted.

Project 03

Omissis

2026

Digital Design

Sound Design

Academic Project

Omissis is an audio experience that explores censorship by transforming declassified Epstein case documents into AI-generated vocal testimonies using Epstein's own voice.

Project 04

CiviCare

2025

Metaproject

Service Design

Academic Project

CiviCare is an educational project that transforms Civic Education into an immersive role-playing game. Guided by an Artificial Intelligence, students collaborate in a narrative campaign, making collective decisions to progressively build a new society.
